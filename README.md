# 32-Bit Processor Design and Verification

## Project Overview
Design and implementation of a 32-bit
processor using a modular HDL approach.
The design separates the datapath and
control unit and uses multi-cycle execution.

## Objectives
- Design a 32-bit processor architecture.
- Develop a datapath and control unit.
- Implement arithmetic and logic operations.
- Simulate and verify instruction execution.

## Architecture
- Control Unit
- Datapath
- ALU
- Register File
- Memory
- Program Counter
- Instruction Register

## Instruction Operations
The project document describes add,
subtract, AND, OR, load, store and branch.

## Project Structure
- RTL: Processor modules
- Testbench: Verification code
- Diagrams: Architecture diagrams
- Simulation: Waveforms and test results
